🦜 Odoo · VoIP team onboarding

From first Odoo request to first VoIP contribution

A code-grounded course for a new engineer: learn the Odoo platform, then own Buy Number, Phone Service, IAP, Telnyx, Wazo, the SIP edge, routing, calls and billing.

28 core lessons · field lessons · 8 modules≈ 5 hours + capstoneZero Odoo and zero telecom assumedPost-merge architecture · verify deployment state
How to use it. Take the lessons in order and do the exercises. Experienced Odoo developers may start at Lesson 11 and keep Lessons 1–10 as reference. When a term or claim is fuzzy, use the lesson's agent prompt to inspect the current code; the point is learning how to navigate reality, not memorizing a frozen snapshot.
Internal course. It describes unreleased/internal architecture and local repository state. Keep it on Odoo-approved infrastructure and re-verify changeable release/branch claims before repeating them.
