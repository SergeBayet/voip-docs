A regression test tells a small story

  1. Arrange the smallest state that exposes the bug.
  2. Perform the public operation a real caller uses.
  3. Assert the externally meaningful result—not private implementation trivia.

For an external service, mock at the actual network boundary and assert the request contract. Do not mock the model method under test or recreate the production algorithm inside the assertion.

Read one case in tests/test_buy_number_wizard.py and one in static/tests/softphone/softphone.test.js. Name what each test deliberately does not prove. The missing real-media proof belongs in a manual call, not a giant unit test.
