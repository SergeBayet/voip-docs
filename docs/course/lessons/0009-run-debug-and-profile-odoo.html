Run, debug & profile Odoo

Debugging gets fast when you know which kind of change needs a restart, a module upgrade, an asset refresh—or none of them.

⏱ 10 min🎯 Create a tight local feedback loop

The command shape

./odoo-bin \
  --addons-path=addons,/path/to/enterprise \
  -d your_database \
  -u voip \
  --dev=all

Use the exact paths and database instructions for your checkout. For test runs, prefer a fresh test database and a focused tag/class before the full module. --stop-after-init is useful for install, upgrade and test-only commands.

Observe before changing

1 · Reproduce
Record inputs, user, database and expected/actual result.
2 · Locate
Use the traceback, network request, logs or failing assertion.
3 · Instrument
Add a breakpoint/log at the narrow boundary.
4 · Prove
Leave the smallest regression test.
